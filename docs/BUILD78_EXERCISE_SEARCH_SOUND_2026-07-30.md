# Build 78 动作搜索与休息提醒交付总结

日期：2026-07-30

仓库：`fivespeedbuck/carbs-king`

发布分支：`codex/build78-exercise-search-sound`

## 用户问题与结果

原动作库虽然有 1324 条离线动作，但大量名称沿用字面翻译或器械分类词。用户搜索“倒蹬”“大剪刀”“双杠臂屈伸”等健身房常用叫法时，需要在上千条结果中反复点开图片猜动作；选错部位、细分肌群或器械后还会直接得到空白列表。

Build 78 保留全部稳定动作 ID 和媒体映射，重做用户可见中文名、常用中文搜索关联和相关性排序。搜索先严格遵守当前筛选，无结果时再依次放宽细分肌群/器械与部位，并显示明确提示。浏览时仍保留常练/热门排序，输入文字后改为精确主名、精确别名、主名开头和部分匹配的相关性顺序。

休息提醒同时收敛为单一到点交付链：已成功安排的 Android `AlarmManager` 或进程内定时器负责到点声音，前台刷新只持久化 finished 状态，不再抢先播放或取消原生提醒。暂停、调整、跳过仍会正确取消或重排。

## 主要改动

- 统一倒蹬机、悍马机、蝴蝶机、大剪刀和鹦鹉螺等器械常用称呼。
- 覆盖倒蹬/腿推、坐姿腿屈伸、哑铃推肩、杠铃实力推、大剪刀、鹦鹉螺、双杠臂屈伸、站姿下夹、哑铃上斜推胸、蝴蝶机夹胸和反向蝴蝶机飞鸟等高频搜索。
- 用户可见主名和搜索别名不保留英文动作名；基础动作通过 `search_priority` 排在辅助、单臂、宽窄握和冷门变式之前。
- 新增筛选放宽服务及页面提示，文本搜索不再被热门排序覆盖。
- Android 原生通知使用静态 `raw/rest_coin`、v3 中文高优先级渠道、`USAGE_ALARM`/闹钟分类，并在通知成功后才记录 delivered。
- 休息截止时间保存到毫秒，剩余秒数向上取整，消除提前 0–2 秒结束。
- 新增 APK 运行时门禁，检查接收器、插件类、权限、通知渠道、原生声音和防裁剪可达性。
- 全量备份补齐 `theme_color`、`age_reference_year` 导入后的运行时同步，并通过导出、模拟卸载、导入逐项一致性验证。
