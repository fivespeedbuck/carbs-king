# 分诊状态

本项目使用下列默认状态词描述需求或缺陷的处理阶段。状态记录在 Obsidian 项目台账中；不要为了使用这些状态词而在 GitHub 创建标签。

| 状态词 | 含义 |
| --- | --- |
| `needs-triage` | 新收到，尚未判断范围、优先级或冻结影响面 |
| `needs-info` | 需要用户补充现象、预期结果或复现条件 |
| `ready-for-agent` | 信息完整，已获准由 Agent 实施 |
| `ready-for-human` | 需要用户作产品决定、授权或执行无法代办的操作 |
| `wontfix` | 已确认不处理，或被新的决定替代 |

当工程技能要求应用某个分诊标签时，使用相同的状态词，并将状态写入对应的 Obsidian 台账。
