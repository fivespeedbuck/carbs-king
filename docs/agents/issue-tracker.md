# 工作追踪

## 权威位置

碳水大王的需求、缺陷、当前状态和下一步计划均在 Obsidian 知识库维护：`D:\obsidian\obsidian\02-项目\碳水大王\00-当前\`。

- 需求：`需求\需求总览.md`
- 缺陷与回归：`修复\修复记录.md`
- 当前事实：`当前状态.md`
- 下一步计划：`下一阶段规划.md`

开始项目工作前，先读取项目总览、当前状态和下一阶段规划；再按任务进入相应台账或专题笔记。新增需求或修复先登记 Obsidian，再实施；完成后回写验收证据。

## GitHub 的用途

GitHub 用于源码、分支、Pull Request 和 Release。普通需求、Bug 和待办不创建或维护 GitHub Issues，除非用户明确要求。
